# 东方播麦对外API对接说明

## 一.授权对接

### 1.基本定义

**OAuth2.0授权流程基本定义**

如果您的应用和东方播麦开放平台对接时需要获取用户隐私数据(如商品、订单等)，为保证用户数据的安全与隐私，您的应用需要取得用户的授权，即获取访问用户数据的授权令牌 Access Token。这种情况下，您的应用需要引导用户完成使用帐号“登录授权”的流程。微盟OAuth2.0流程采用国际通用的OAuth2.0标准协议作为用户身份验证与授权协议，支持网站、手机客户端、桌面客户端。

| 参数          | 说明                                                         |
| ------------- | ------------------------------------------------------------ |
| client_id     | 开发者应用用于发起Oauth_2.0授权的凭证（可在“开发者中心”创建应用后获取到） |
| client_secret | 开发者应用用于发起Oauth_2.0授权的凭证（可在“开发者中心”创建应用后获取到） |
| redirect_uri  | 应用发起请求时，所传的回调地址参数，用于接收平台返回的数据   |
| access_token  | 开发者完成授权后，被颁发调用API 的凭证                       |
| refresh_token | 刷新access_token的凭证，当access_token过期时，开发者可以用refresh_token刷新得到新的access_token |

### 4.接入流程

#### 1）获取code

**点击指定应用的授权按钮**

将自动发送code到应用填写的url，调用格式为：https://xxxxxxx.com/xxx/xxx?code=code

请开发程序用于接收code，然后根据获取的code进行后续流程。

![image-20211207155736088](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20211207155736088.png)



> 1.code只有10分钟有效期，过期后请重新点击授权按钮发送新的code  
>
> 2.一个code只能使用一次



#### 2）根据code换取Access Token

**请求地址**：https://m.orientalmall.com.cn/api/external/web/token/authorizationToken

**请求方式**: POST

**请求参数**

| 名称         | 是否必选 | 参数值 | 参数释义           |
| ------------ | -------- | ------ | ------------------ |
| clientId     | 是       |        | 创建应用时获得。   |
| clientSecret | 是       |        | 创建应用时获得。   |
| code         | 是       |        | 上一步获取code得到 |

**响应参数**

| 名称                  | 类型   | 返回value           | 说明                                  |
| --------------------- | ------ | ------------------- | ------------------------------------- |
| clientId              | String |                     | 授权应用id                            |
| accessToken           | string |                     | Access_token                          |
| expiresIn             | Date   | yyyy-MM-dd HH:mm:ss | Access_token过期时间,默认2小时        |
| refreshToken          | string |                     | Refresh_token，可用来刷新access_token |
| refreshTokenExpiresIn | number | yyyy-MM-dd HH:mm:ss | Refresh_token有效期，默认7天          |

> 1.通过code拿到accessToken和refreshToken
>
> 2.用refreshToken刷新获取新的accessToken，accessToken有且只有效期2h
>
> 3.保证至少2小时以内刷新一次token，refreshToken将自动续期，每次刷新refreshToken有效期增加2小时，但是最大只有7天。
>
> 4.获取新token或者刷新token都会强行导致旧token有效期剩余15分钟，不会立刻失效旧token，防止网络延迟与波动。（假如tokenA剩余有效期30分钟，此时调用了刷新token接口，获取了新的tokenB，那么此时tokenA剩余有效期则变为15分钟。）
>
> 5.当refreshToken失效时，需要从code授权重新开始。

#### 3）根据refreshToken刷新accessToken

**请求地址**：https://m.orientalmall.com.cn/api/external/web/token/authorizationRefreshToken

**请求方式**: POST

**请求参数**

| 名称         | 是否必选 | 参数值 | 参数释义         |
| ------------ | -------- | ------ | ---------------- |
| clientId     | 是       |        | 创建应用时获得。 |
| clientSecret | 是       |        | 创建应用时获得。 |
| refreshToken | 是       |        | refreshToken     |

**响应参数**

| 名称                  | 类型   | 返回value           | 说明                                  |
| --------------------- | ------ | ------------------- | ------------------------------------- |
| clientId              | String |                     | 授权应用id                            |
| accessToken           | string |                     | Access_token                          |
| expiresIn             | Date   | yyyy-MM-dd HH:mm:ss | Access_token过期时间,默认2小时        |
| refreshToken          | string |                     | Refresh_token，可用来刷新access_token |
| refreshTokenExpiresIn | number | yyyy-MM-dd HH:mm:ss | Refresh_token有效期，默认7天          |

### 5.注意

后续会增加调用频次限制，注意官方通知。
